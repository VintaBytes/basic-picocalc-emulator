# BASIC PicoCalc Emulator 0.3.10-dev.0 (pre-release)

Primera compilación candidata de la versión independiente para Linux x86_64.

- Emulador de escritorio de PicoCalc con intérprete BASIC compatible con un subconjunto de MMBasic.
- Interfaz con pantalla LCD y teclado virtual; varias presentaciones fotográficas.
- Editor BASIC, ejecución de programas, gráficos y unidades virtuales.
- Título de ventana: **PicoCalc BASIC**.

**Estado:** versión de desarrollo. No se garantiza compatibilidad total con MMBasic/PicoMite.

**Archivo:** `BASIC-PicoCalc-Emulator-0.3.10.dev0-x86_64.AppImage`  
**Verificación:** el archivo `SHA256SUMS` adjunto a la publicación contiene
la huella SHA-256 del AppImage generado y auditado automáticamente.

## Uso

En una distribución Linux x86_64:

```bash
chmod +x BASIC-PicoCalc-Emulator-0.3.10.dev0-x86_64.AppImage
./BASIC-PicoCalc-Emulator-0.3.10.dev0-x86_64.AppImage
```
